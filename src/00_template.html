How it works

Plan to tour in three steps.

01

Upload your floor plan

Drop a JPG, PNG or PDF, from builder brochures to hand sketches. Sign in with Gmail and answer three quick questions.

02

AI detects & builds

Walls, rooms, doors, windows and dimensions are detected. Review the names, then watch the walls rise and the furniture drop into place.

03

Explore with Aria

Orbit, cut away, or walk at eye level. Take the narrated tour and tell Aria what to change; it updates live.

Built on Gemma 4

Open models. Real intelligence.

DIMORA calls Google's open Gemma 4 models through the Gemini API. They read your plan, power Aria's actions, write tour narration and match inspiration photos. No key? The on-device engine still runs everything.

// Ask Gemma 4 to read labels, doors & windows on a floor plan
const res = await fetch(
  `https://generativelanguage.googleapis.com/v1beta/models/gemma-4-31b-it:generateContent?key=${KEY}`,
  { method: 'POST', headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ contents: [{ role: 'user', parts: [
      { text: 'Name every region, give plan_width_m, doors & windows. JSON only.' },
      { inline_data: { mime_type: 'image/jpeg', data: planBase64 } }
    ] }] }) });
const plan = extractJSON((await res.json()).candidates[0].content.parts
  .filter(p => !p.thought).map(p => p.text).join(''));
buildHome(plan); // → walls rise, furniture drops in, Aria says hi 👋
